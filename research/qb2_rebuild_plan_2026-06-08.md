### What changed between 2026-06-07 failure and 2026-06-08 PASS

Nothing on disk:
- tt-metal source: no edits since clone (`find -newer` after May 15 returns 0)
- JIT cache: no new entries written today (most-recent dir mtime = May 16)
- pre-compiled FW dir: untouched
- transformers: 5.10.2 (was upgraded 2026-06-07 PM, before the failure)
- tt-smi 5.0.0, firmware 19.6.0 (no driver update)

Plausible causes for the transient failure:
1. **Stale device state / fabric context** — the `tt-smi -r 0,1,2,3` reset
   embedded in `run_remote_qb2.sh` cleared whatever was wrong. (qb2 uptime is
   3 days; HARDWARE wasn't power-cycled.)
2. **Concurrent JIT compile races** — if a prior `python` proc was still
   building a kernel when the gate fired, the SFPI front-end might see a
   half-written artifact. yesterday's user log mentioned an idle `gm4` tmux
   that was killed earlier; possible the JIT compile-step recovered.
3. **Misdiagnosis** — the failure happened in a hot-iterated drafter bringup
   path with possibly-non-canonical kernel shapes. The error might have come
   from a sibling shape we didn't include in the 4-case isolation suite.

## Recommendation

**Do not rebuild qb2 today.** Risks of a rebuild without a reproducible bug:

- ~30-45 min wall time loss
- May surface NEW issues (new compiler/cache state), as qb2 currently uses
  `g++-12` whereas qb1 uses `clang++-20`; matching to clang might fix or break
  unrelated things
- Could disturb the `_ttnn.so.pre_gdn_20260515` snapshot kept as a fallback
- May require rebuilding the 9 owned kernels (forward-looking risk for
  someone resuming the qwen36 chain)

**Instead, do this** if/when the bug recurs:

1. Re-run the gate first thing — confirm it's still failing, not transient.
2. Capture the full stderr context (what kernel parameters were being JIT-compiled).
3. Clear ~/.cache/tt-metal-cache/ and re-run gate (cheap, ~2 min).
4. If gate still fails, only THEN consider rebuilding. Match qb1's preset
   (`release` → `build_Release/`, clang++-20) so the two hosts converge.
