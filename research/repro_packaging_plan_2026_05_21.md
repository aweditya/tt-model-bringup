## 4. Risk callouts

- **tt-metal drift:** Rebuilding `ttnn` against a newer tt-metal can break `owned_ops` C++ ABI (nanobind types change). Pin a known-good SHA in `docs/SETUP.md`.
- **HF_TOKEN gating:** Bootstrap dies at `AutoTokenizer.from_pretrained` without it. Make `.env.example` first-class.
- **Hardcoded `~/tt-xla`:** Three places in `server.py`, one in `server_tp.py`. Demo-A breaks if cloned elsewhere — patch to `os.path.dirname(__file__)` resolution.
- **qb1 vs qb2:** qb1 has no inter-chip fabric — `server_tp.py` will hang setting `FABRIC_1D`. README must enforce host → demo mapping.
- **Mesh wedge:** Hard-kill of `server_tp` requires `tt-smi -r 0,1,2,3`. Document in TROUBLESHOOTING.
