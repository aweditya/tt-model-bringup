# B16 On-Device 35B-A3B Server — Handoff (updated 2026-05-21 late)

## Where things stand

`server_35b_ttnn.py` has the FULL on-device forward architecture in place:

- **Bootstrap**: opens (1,4) mesh + FABRIC_1D + uploads all 40 layers'
  weights as sharded ttnn tensors (~80s one-time)
- **MoE block** (`moe_forward_ttnn`): routed (8 selected experts via
  ttnn.slice on per-chip [256, H, I] table) + shared (with sigmoid gate) +
  all_reduce. **Full math.**
- **DN block** (`dn_forward_ttnn`): all 4 in_proj matmuls + g/beta + full
  recurrence (state*g, kv_mem, delta, state update, output query) + RMSNormGated
  + out_proj. **conv1d still placeholder** (silu(mixed_qkv) instead of real
  state-shift + sum*conv_weight + silu). L2_norm on Q/K skipped. Head
  repeat 4→8 uses concat instead of interleave.
- **Attn block** (`attn_forward_ttnn`): Q/K/V matmuls + gate split + q/k_norm
  + sigmoid(gate) * v + o_proj. **RoPE placeholder** (no rotation applied).
  **KV cache placeholder** (no cache evolution; uses first KV head only,
  ignores chip-to-KV-head mapping).
- **Full layer composition** (`layer_forward_ttnn`): input_layernorm +
  (DN OR attn dispatch by layer_type) + residual + post_attention_layernorm
  + MoE + residual. **Works end-to-end on layer 0** (smoke output norm
  18.96, sensible magnitude).

## Reference patterns (don't re-derive)

- Mesh tensor ranks: ttnn.matmul output is rank 3 (per-chip view padded).
  ShardTensorToMesh tensors have logical shape with leading 1 in mesh dim
  (NOT NCHIPS). Slice begins/ends must match tensor rank — use len(shape)
  to detect.
- ttnn.all_reduce: only `cluster_axis` kwarg (sum is default).
- ttnn.to_torch: needs `mesh_composer=ttnn.ConcatMeshToTensor(mesh, dim=0)`
  for mesh tensors; take [0] of result for replicated tensors.
- (1+w) layernorm convention: pre-add 1.0 at upload to use stock
  ttnn.rms_norm. Applied to `input_layernorm` + `post_attention_layernorm`
  weights. Not applied to `linear_attn.norm.weight` (Qwen3_5MoeRMSNormGated
  uses bare w).
- Expert table format: per-chip `experts_gate_up` [256, HIDDEN, INTERMEDIATE]
  (TRANSPOSED from HF [256, INTERMEDIATE, HIDDEN]); `experts_down` similarly.
  Slice rank-4 begins=[0, e, 0, 0] ends=[1, e+1, INTERMEDIATE, HIDDEN].
