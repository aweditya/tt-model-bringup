## Architecture decisions already made (don't re-litigate)

- Per-chip weight layout (validated B10/B11/B12.8):
  - DN: V-head sharded (8 heads/chip); in_proj_qkv [2048, 2048] per chip
  - attn: Q-head sharded (4 heads/chip), KV REPLICATED (2 heads < 4 chips)
  - MoE: intermediate-dim sharded (128/chip); 256 experts × [256, 2048]
        TRANSPOSED to [E, H, I] format for matmul-friendly layout

- RMSNorm convention: `input_layernorm` + `post_attention_layernorm` use
  `output * (1 + w)`; pre-add 1.0 at upload. `linear_attn.norm.weight` +
  `q_norm` + `k_norm` use bare `w`.

- MRoPE collapses to standard partial RoPE for text-only inference
  (validated B3). Use 27B RoPE infra unchanged.

- GQA chip-to-KV-head mapping: chip c → KV head c // (NCHIPS / NUM_KV_HEADS)
  = c // 2. So chip 0+1 → KV head 0, chip 2+3 → KV head 1.
